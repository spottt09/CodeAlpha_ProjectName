# Scope

## Assessment Scope
This project focuses on security testing of the OWASP Juice-Shop Web application in a locally hosted lab environment. The assessment covers 8 completed challenges, with testing limited to the application functionality and vulnerability scenarios explored during those chllenges.

## In-Scope
- The locally hosted OWASP Juice Shop Web application
- The eight completed challenges documented in this report
- Manual security testing and reconnaissance relevant to the selected challenges.
- Analysis of observed application behavior and potential security weakness
- Documentation of vulnerability findings, testing methodology, actions, potential impact and severity, recommended mitigation, limitation and lessons learned.

## Out-Of-Scope
- Testing against publicly accessible or production systems
- Attacking external websites, servers, or infrastructure
- Denial of Service testing or activities intended to disrupt availability
- Accessing real user's accounts or data
- Testing vulnerabilities beyond the defined lab environment and selected challenges

## Assessment Limitations
This report documents eight selected challenges rather than a comprehensive security assessment of the entire OWASP Juice Shop application. Screen recording of three challenges are provided.

## Authorization
All testing is intended to take place within the local, intentionally vulnerable OWASP Juice Shop lab. No testing of systems without explicit authorization is included in this assessment.
